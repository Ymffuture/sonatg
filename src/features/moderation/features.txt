**How it works together**
1. `detectionEngine.ts` runs instantly, client-side, no network — blocked words + pattern signals (repeated targeting, message bursts, shouting, aggressive punctuation).
2. Only if that finds *something* worth a second look, `aiModeration.functions.ts` fires a server-side call (same OpenRouter gateway pattern your `ai.functions.ts` already uses) to classify sarcasm, coded insults, leetspeak, and polite-sounding pile-on messages the word list can't catch.
3. `mergeVerdicts.ts` combines both into one final `ModerationResult` — AI only escalates severity, never overrides a clean local result on its own (fails open on parse/network errors so a flaky AI call never blocks sends).
